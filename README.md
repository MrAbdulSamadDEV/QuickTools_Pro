# QuickTools Pro v3

A compact Chrome extension for common browser, text, and developer tasks.

## Included Features
- Screenshot of visible tab
- Clean URL / tracking parameter removal
- Duplicate tab cleanup
- Save current page as HTML
- Print / PDF
- Search and translate selected page text
- Copy page title / URL
- Text transforms, sorting and unique lines
- **Developer Tools**: page info, view source, JSON formatter, URL decode, Base64 encode/decode
- Clipboard history
- Quick notes

## Design Principles
- Dark, compact UI
- No emojis
- No remote JavaScript libraries
- No fake/non-working OCR or QR tools
- Reduced permissions compared with the previous build

## Installation Guide
1. Extract the ZIP file.
2. Open `chrome://extensions` in Google Chrome.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked**.
5. Select the `QuickTools_Pro_v3` folder.

## Chrome Web Store Publishing
This package is Manifest V3. Before publishing, complete the Store listing and Privacy tabs in the Chrome Web Store Developer Dashboard and ensure 2-step verification is enabled on your Google account.
