NEXA Tools v8.0.0 - Ultimate Browser Toolkit

Monochrome production build for Google Chrome (Manifest V3) with Side Panel, Full Screenshots, Screen Recording, Media Downloader & Offline QR Studio.

Changelog v8.0.0:
1. QR Code Scanner (Offline & Multi-Mode):
   - Active Webpage Scan: 1-click capture & scan QR code directly from current screen/tab.
   - Camera Scan: Real-time camera viewfinder with automated detection.
   - File & Paste Scan: Drag & drop, browse image file, or press Ctrl+V to paste from clipboard.
   - Multi-pass hardware BarcodeDetector + Pure JS offline fallback (qrscan-local.js).
   - Instant copy, "Open URL ↗" button for links, and "Generate QR" transfer.

2. High-Definition Screenshots:
   - Visible View Screenshot: Instant capture of the visible view with copy-to-clipboard and PNG download.
   - Full Page Scrolling Screenshot: Automatically scrolls through long pages, stitches slices with retina devicePixelRatio support, restores scroll position, and downloads full-length PNG.

3. Screen Video Recorder:
   - Record active tab, application window, or full screen.
   - Optional audio recording (tab/system audio and microphone mixing).
   - Live blinking REC indicator, live timer (MM:SS), Pause/Resume, and Stop & Save.
   - Built-in video player preview with one-click WebM download.

4. Web Page Media & Icon Studio:
   - Extracts all <img> tags, lazy-load sources, and srcset images.
   - Extracts all favicons, touch icons, and app icons (<link rel="*icon*"> and /favicon.ico).
   - Extracts inline <svg> elements and serializes them to clean downloadable .svg files.
   - Extracts CSS background images, video posters, and OpenGraph meta images.
   - Category filtering (All, Images, Icons, SVGs) + Hide tiny tracking pixels (<30px).
   - Batch Download All & Download Selected with download throttling protection.

5. Extra Useful Features:
   - Float Video (PiP): 1-click Picture-in-Picture for any video on the page.
   - Smart Dark Mode: High-contrast comfortable dark mode toggle.
   - Text & Reading Stats: Word count, character count, and estimated reading time.
   - Ultra Audio Boost: Up to 2000% volume with dynamic limiter & peak compressor.

How to install in Chrome:
1. Extract the ZIP archive (or load the nexa_extension folder).
2. Open Google Chrome and navigate to chrome://extensions/
3. Turn ON "Developer mode" (toggle switch in the top-right corner).
4. Click "Load unpacked" and select the extension folder.
5. Pin "NEXA Tools" to your toolbar.
